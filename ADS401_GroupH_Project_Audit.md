# ADS401 Group H Project Audit

## Theme

Course theme: Evaluating AI Integration at XJTLU.

Project theme: Usability Evaluation of the XJTLU Museum AI System.

The project is bounded to one system, one user group, and four visitor tasks. It evaluates actual visitor interaction rather than asking general opinions about AI.

## Research chain

| Stage | Current evidence or material |
|---|---|
| Context | XJTLU Museum AI-supported visitor guidance |
| Users | XJTLU students and staff, 18+ |
| RQ1 | Can visitors complete the four tasks? |
| RQ2 | How usable and efficient is the system? |
| RQ3 | What barriers and improvements do visitors report? |
| Design | Moderated task-based usability study |
| Sample | 12-15 participants, convenience recruitment |
| Observed data | Task success, time, errors, assistance |
| Self-report | 10-question bilingual Wenjuanxing survey |
| Standard measure | SUS, 10 items |
| Domain measures | Content relevance, navigation, recovery, trust, cognitive load |
| Statistics | Binomial test, SUS benchmark test, Spearman correlations |
| Qualitative | Think-aloud notes and open questionnaire responses |

## Hypotheses

- H1: At least 80% independent success for each task.
- H2: SUS reaches or exceeds the benchmark of 68.
- H3: Task ease and task confidence are positively associated with SUS.
- H4: Onboarding, navigation, answer clarity, or recovery barriers recur.
